# CLAUDE.md — klokie.com

**Affiliate links:** outbound product links are plain URLs. Codes are added
at build time from the shared registry in `@klokie/theme/affiliates`
(`klokie-theme/src/affiliates/programs.ts`). Never hand-paste referral URLs.
`/go/<id>` (in `src/worker.js`) serves the same registry for links used
outside the site. To change a code, edit the theme, then run
`pnpm update @klokie/theme` here.

Always read `DESIGN.md` before making any visual or UI decision. All font
choices, colors, spacing, layout, and aesthetic direction are defined there.
Do not deviate without explicit user approval. In QA mode, flag any code
that doesn't match DESIGN.md.

Content source of truth is the vault: `~/vault/work/klokie-com/PUBLIC/`
(synced into `src/content/`). `src/content/cases/en/*` with
`generated: true` frontmatter is produced by the vault's
`bin/migrate-cases.mjs` — edit the source, not the output.

Standards: `~/vault/resources/programming/klokie-web-stack.md` and
`web-project-standards.md` (canonical host www.klokie.com).

## Agent-facing surface (don't break these)

- Every HTML page ships a Markdown twin at `<route>/index.md`, generated by
  `src/lib/markdown-routes.ts`. New route shapes must be added there too.
- `src/worker.js` negotiates `Accept` (acceptmarkdown.com): Markdown when the
  client prefers it, HTML otherwise, `Vary: Accept` on both, `Link:
rel="alternate"` on HTML, `406` when nothing we produce is acceptable, and a
  Markdown-bodied `404` for clients that didn't ask for HTML.
- `/llms.txt` (llmstxt.org shape) is the agent map _and_ the when-to-use
  instruction file; `/llms-full.txt` is the whole site in one fetch.
- `pnpm test` covers all of the above; `scripts/verify-agent-readiness.sh
[origin]` checks a live deploy (defaults to production).
